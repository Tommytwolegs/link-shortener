Before you start (do all four, in order)

  1. Open chrome://extensions, find Rather's Link Shortener, and click the reload arrow ⟳.
  2. Confirm the version shown on that card is 1.13.0. If it says 1.12.0, the unpacked folder isn't the repo build — fix that first.
  3. Open the extension popup and make sure the top switch Shorten All Links is ON.
  4. Every test below wants a fresh tab unless it says otherwise. Checkbox state on this page saves itself — you can close and come back.
